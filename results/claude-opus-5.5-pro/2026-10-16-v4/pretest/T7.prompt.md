# Задача

Что выведет программа?
```python
from collections import deque

D = 50000
deck = list(range(D))
start = list(deck)
count = 0
while True:
    pile = deque()
    for i, card in enumerate(deck):
        if i % 2 == 0:
            pile.appendleft(card)   # кладём наверх стопки
        else:
            pile.append(card)       # подкладываем под низ стопки
    deck = list(pile)
    count += 1
    if deck == start:
        break
print(count)
```
