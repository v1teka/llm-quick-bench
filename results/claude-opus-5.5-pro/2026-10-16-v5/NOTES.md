# Pro v5, Claude Opus 5.5 (16.10.2026): программирование и открытые конструкции

Протокол v5 — v4 плюс два набора, каждый одним ответом:
- **Программирование** — три оптимизационные задачи, решение — программа на Python, она запускается на скрытых экземплярах с ограничением времени;
- **Конструкции** — четыре открытые математические задачи, ответ — конструкция, её проверяет и меряет код.

У обоих наборов нет потолка «решил — не решил»: балл растёт плавно от простой эвристики (0) до эталона или лучшего известного результата (1).

| Диалог | Что | Откуда ответы |
|---|---|---|
| `dialog/house`, `dialog/{arc,optics,nav,matryoshka}` | дом и прежние наборы | те же ответы, что в [v4](../2026-10-16-v4/NOTES.md) |
| `dialog/code/01_task_code` | программирование одним ответом — **в счёт** | прогон 16.10 |
| `dialog/construct/01_task_construct` | конструкции одним ответом — **в счёт** | прогон 16.10 |
| `dialog/{code,construct}/N/` | те же задачи по одной на запрос — диагностика | прогон 16.10 |
| `pretest/` | ранние версии наборов, см. ниже | прогон 16.10 |

Опрашивали так же, как раньше: субагент Claude Code (модель `claude-opus-5-5`) без инструментов, разрешено одно чтение файла с промптом. Токены, время и превышения лимита взяты из транскриптов (`*.meta.json`).

## Как искали задачи

1. **Классическое программирование** (`pretest/code1`, набор `code1`). Четыре авторские задачи олимпиадного уровня со скрытыми тестами: кольцо ламп (линейная алгебра над GF(2) с поправкой на чётность), повторы без наложения (суффиксный автомат), Σ НОД² до 2·10⁹ (решето Дю), ожидаемое число компонент кактуса. Эталоны сверены с перебором. Opus решил **4 из 4 на 100%** и одним ответом (2.5 минуты, 16 тыс. токенов), и по одной (20–45 секунд на задачу). Для него это слишком легко, поэтому набор ушёл в историю.
2. **Оптимизационное программирование** (сейчас в счёте). Коммивояжёр на 2000 городов, раскраска случайных графов, упаковка прямоугольников в полосу. Ограничение — 10 секунд CPython. Эталоны — программы на C из `qbench/hard/tasks/opt_ref/`, долгий прогон. В первой версии эталоном упаковки был результат `strip.c`, и программа Opus на Python его обошла (480 против 494, `pretest/code2-old-strip-ref`). Поэтому эталон упаковки заменён нижней границей ⌈Σ w·h / W⌉, а тур коммивояжёра пересчитан 10-минутным прогоном.
3. **Конструкции v1** (`pretest/construct1`). Четвёртой задачей была сортирующая сеть на 12 входов. По одной на запрос Opus выдал **оптимальную сеть из 39 компараторов** за 45 секунд: её он помнит наизусть. Сеть заменена задачей Таммеса (13 точек на сфере), но Opus вспомнил и её оптимум: 57.13° при известном 57.1367°. Нерешённых по памяти задач осталось две: «ни трёх на прямой» и код Хэмминга.

## Программирование — 91% одним ответом, 74% по одной

| Задача | Экземпляр | Одним ответом | По одной | База | Эталон |
|---|---|---|---|---|---|
| Коммивояжёр | равномерный, 2000 | 32.808·10⁶ | 32.993·10⁶ | 42.458·10⁶ | 32.614·10⁶ |
| | кластеры, 2000 | 16.084·10⁶ | 16.646·10⁶ | 19.796·10⁶ | 15.895·10⁶ |
| Раскраска | G(250, ½) | 29 цветов | 29 | 36 | 28 |
| | G(500, ⅒) | 13 | 13 | 16 | 13 |
| Упаковка | 150 прямоугольников | 477 | 515 | 548 | 464 (граница) |
| | 250 прямоугольников | 874 | 935 | 1001 | 848 (граница) |

Opus пишет для всех трёх задач сильные эвристики:
- для коммивояжёра — Or-opt и 2-opt по спискам соседей с возмущением;
- для раскраски — TabuCol;
- для упаковки — отжиг по порядку укладки.

Одним ответом получилось лучше, чем по одной: 36.6 тыс. токенов за 5.6 минуты против 20.8 тыс. на одного коммивояжёра. Баллы зависят от скорости машины: эвристики работают до конца лимита времени. Здесь прогон шёл на 4-ядерной виртуальной машине, по одному решению за раз.

## Конструкции — 77% одним ответом, 86% по одной

| Задача | Одним ответом | По одной | Лучшее известное |
|---|---|---|---|
| Ни трёх на прямой, 24×24 | 26 точек — 54% | 28 — 58% | 48 |
| 13 точек на сфере (Таммес) | 57.1367° — 100% | 57.1300° — 100% | 57.1367° |
| 10 точек в квадрате | 0.416667 — 95% | 0.416667 — 95% | 0.421280 |
| Код длины 10, расстояние 4 | 32 слова — 60% | 38 — 90% | 40 |

Одним ответом Opus потратил 50.5 тыс. токенов. По одной на запрос на «точки в квадрате» ушло 150 тыс. токенов (одно превышение лимита), а на код — 96 тыс. Набор целиком снова проигрывает задачам по одной: например, для кода получилось 32 слова вместо 38. Как и в навигации, модель сама решает, сколько вложить в каждую задачу, и на набор вкладывает меньше.
