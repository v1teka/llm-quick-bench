## Задача 1. Упаковка в полосу (ограничение времени 10 с)

Есть полоса ширины W и n прямоугольников w_i × h_i. Разместите все прямоугольники в полосе без
поворотов и без наложений (касаться сторонами можно) так, чтобы высота занятой части была как можно меньше.

**Ввод.** n W, затем n строк «w h» (целые; n = 150 или 250, W = 100).

**Вывод.** n строк «x y» — целые координаты левого нижнего угла каждого прямоугольника: 0 ≤ x, x + w ≤ W, y ≥ 0.

**Оценка.** Высота H = max(y + h) сравнивается с алгоритмом полок NFDH (H₀, 0 баллов) и с эталоном
(долгий прогон; полный балл): балл = (H₀ − H)/(H₀ − H*), от 0 до 1. Наложение или выход за полосу — 0.
