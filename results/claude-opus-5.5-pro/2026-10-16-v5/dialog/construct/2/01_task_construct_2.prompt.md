# Открытые конструкции

У этих задач нет единственного ответа: сдай конструкцию, код проверит её корректность и измерит качество. Балл растёт плавно: простая корректная конструкция даёт немного, полный балл — результат на уровне лучшего известного. Некорректная конструкция — 0 баллов, поэтому лучше сдать чуть более слабую, но проверенную.

## Задача 1. Сортирующая сеть на 12 входов

Построй сортирующую сеть на 12 входов (номера 0…11) с как можно меньшим числом компараторов. Компаратор `[i, j]` при i < j ставит на позицию i меньшее из двух значений, на j — большее; компараторы применяются по порядку. Сеть должна сортировать по возрастанию любой вход. Ответ — список пар `[i, j]`. Если сеть сортирует не всё — 0 баллов.

## Формат ответа
ОДИН блок JSON без пояснений: {"1": [...]}
