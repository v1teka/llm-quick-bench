# Открытые конструкции

У этих задач нет единственного ответа: сдай конструкцию, код проверит её корректность и измерит качество. Балл растёт плавно: простая корректная конструкция даёт немного, полный балл — результат на уровне лучшего известного. Некорректная конструкция — 0 баллов, поэтому лучше сдать чуть более слабую, но проверенную.

## Задача 1. Ни трёх на прямой 24×24

Выбери как можно больше узлов решётки 24×24 (координаты — целые 0…23) так, чтобы никакие три выбранных узла не лежали на одной прямой (любого наклона). Ответ — список пар `[x, y]`. Если найдётся тройка на одной прямой или повтор — 0 баллов.

## Задача 2. 13 точек на сфере

Расставь 13 точек на единичной сфере так, чтобы наименьший из углов между ними (если смотреть из центра) был как можно больше (задача Таммеса). Ответ — список троек `[x, y, z]` (не меньше 9 знаков после запятой); каждая тройка нормируется на длину, нулевой вектор — 0 баллов.

## Задача 3. 10 точек в квадрате

Расставь 10 точек в единичном квадрате [0, 1]×[0, 1] так, чтобы наименьшее из попарных расстояний было как можно больше. Ответ — список пар чисел `[x, y]` (не меньше 9 знаков после запятой). Точки вне квадрата (допуск 10⁻⁹) — 0 баллов.

## Задача 4. Код длины 10, расстояние 4

Найди как можно больше двоичных слов длины 10, любые два из которых различаются не менее чем в 4 позициях (кодовое расстояние Хэмминга ≥ 4). Ответ — список строк из 0 и 1. Если найдётся пара слов на расстоянии меньше требуемого или повтор — 0 баллов.

## Формат ответа
ОДИН блок JSON без пояснений: {"1": [...], "2": [...], "3": [...], "4": [...]}
