## Слой 2. Программирование
Что выведет программа при D = 2 · (500000 + (ответ слоя 3 mod 500000))?
```python
from collections import deque

deck = list(range(D))
start = list(deck)
count = 0
while True:
    pile = deque()
    for i, card in enumerate(deck):
        if i % 2 == 0:
            pile.appendleft(card)   # кладём наверх стопки
        else:
            pile.append(card)       # подкладываем под низ стопки
    deck = list(pile)
    count += 1
    if deck == start:
        break
print(count)
```

## Слой 0. Кубик
Кубик стоит на клетке `S` поля 10 × 10. Верхняя строка поля — север, правый столбец — восток.
Грани кубика в начале: верх R, низ O, север G, юг B, восток Y, запад W (R — красный, O — оранжевый, G — зелёный, B — синий, Y — жёлтый, W — белый; противоположные пары R–O, G–B, Y–W).
Ход N/S/E/W — кубик перекатывается через нижнее ребро на соседнюю клетку в этом направлении (при ходе E грань, смотревшая на восток, становится нижней, а верхняя — восточной).
Когда кубик встаёт на клетку: `.`, `S`, `G` — ничего; `@` — поворотный круг: поворот на 90° по часовой стрелке, если смотреть сверху (северная грань становится восточной, восточная — южной…; верх и низ не меняются); `%` — переворот на 180° вокруг оси север–юг (верх и низ меняются местами, восток и запад — тоже); `#` — яма, вставать нельзя; уходить за край поля тоже нельзя.
Пусть i = (ответ слоя 1) mod 24. Цвета пронумерованы в порядке R, O, G, B, Y, W. Целевая верхняя грань — цвет номер ⌊i / 4⌋ (с нуля); целевая северная — цвет номер (i mod 4) среди четырёх цветов, соседних с верхним (в том же порядке R, O, G, B, Y, W, без верхнего и противоположного ему).
Поле:
```
#.S.....#@
.....%....
..%..%..#@
..#....#..
#..#.#....
..%.......
.%...#.#@.
#@..#.#...
.#.#G##..#
.#.#.....@
```
Найдите кратчайший маршрут из S в G, после которого у кубика на G целевые верхняя и северная грани. Полный балл — за самый короткий маршрут; верный, но длиннее оптимума на 1–2 хода — 0.85, ещё длиннее — 0.7.
