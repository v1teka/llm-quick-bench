## Задача 1. Повторы без наложения (ограничение времени 6 с)

Дана строка s из строчных латинских букв. Посчитайте, сколько существует **различных** непустых строк t,
которые входят в s как подстрока хотя бы два раза **без наложения**: найдутся вхождения, начинающиеся с позиций
i и j, где j ≥ i + |t|.

**Ввод.** Одна строка s, 1 ≤ |s| ≤ 10⁵.

**Вывод.** Одно число.
