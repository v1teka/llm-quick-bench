# Pro v3, Claude Opus 5.5 (16.10.2026): матрёшка v1

Четвёртый набор «Кубик» здесь заменён «Матрёшкой» первой версии: задача о кубике, в которую пять раз вложена классическая олимпиадная задача:
- IMO 1988 №6;
- упругий бильярд Гальперина;
- DP «домино 4×n»;
- игра Уитхоффа;
- «Ханой на 4 стержнях».

Матрёшка сдавалась по слою на сообщение одного диалога.

| Диалог | Что | Откуда ответы |
|---|---|---|
| `dialog/house`, `dialog/{arc,optics,nav}` | дом и три набора | те же ответы, что в [официальном прогоне](../2026-10-16/NOTES.md) |
| `dialog/matryoshka1/` (копия `dialog/matryoshka/`) | матрёшка v1, по слою на сообщение | прогон 16.10, субагент без инструментов |

Итог: **91%**. Матрёшка — **100%**: все 6 слоёв верны, цепочка 6/6. Итог вышел выше, чем в официальном прогоне, поэтому классика для матрёшки оказалась слишком лёгкой. Отсюда [v2](../2026-10-16-v4/NOTES.md).

В коде эта версия теперь называется `matryoshka1`. Воспроизвести прогон:

```bash
python -m qbench pro --model x --label "Claude Opus 5.5" --manual results/claude-opus-5.5-pro/2026-10-16-v3 \
    --item-diag --tasks arc,optics,nav,matryoshka1 --no-video
```
