# Эталоны набора «Программирование»

Программы на C, которыми посчитаны эталонные значения в `qbench/hard/data/opt_ref_<seed>.json`. Балл экземпляра — (база − результат)/(база − эталон), обрезанный до [0, 1].

| Задача | Программа | Алгоритм |
|---|---|---|
| Коммивояжёр | `tsp.c` | итеративный локальный поиск: 2-opt и Or-opt по 10 ближайшим соседям, возмущение double-bridge на участке тура |
| Раскраска графа | `color.c` | TabuCol (Hertz, de Werra) с последовательным уменьшением числа цветов |
| Упаковка в полосу | `strip.c` | нижне-левая укладка с заполнением дыр и отжиг по порядку укладки |

Для упаковки эталон — не результат `strip.c`, а нижняя граница ⌈Σ w·h / W⌉: Opus 5.5 в первом прогоне обошёл `strip.c` программой на Python, и потолок оказался бы слишком низким.

Как пересчитать:

```bash
gcc -O2 -o tsp tsp.c -lm && ./tsp 600 SEED < экземпляр      # первая строка вывода — длина тура
gcc -O2 -o color color.c && ./color 600 SEED < экземпляр    # первая строка — число цветов
```

Экземпляры для seed — `qbench.hard.tasks.opt.make_instances(seed)`. Решения эталонов проверены теми же функциями `eval_*`, что и решения моделей.
